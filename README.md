## 目录结构一览
|  文件   | 解释  |
|  ----  | ----  |
| pycache  | python缓存文件夹 |
| build | 构建exe的文件 |
| dist | 构建后的exe存在这里 |
| source | 储存算法脚本 |
| main.py | 主程序 |
## 打包exe
安装pip插件pyinstaller
```
pip install pyinstaller
```
打包成exe(关闭cmd窗口，设置favicon.ico为exe图标)
```
pyinstaller -w -F -i favicon.ico main.py
```
